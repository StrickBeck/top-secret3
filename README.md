# Кремнёвый нож из Ботая — экран для музея

Next.js + three.js. Проигрывает 90-секундный фильм из `public/models/botai.glb` (экспорт из `museium_web.blend`) и даёт свободную камеру оператора.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install        # заодно копирует декодер Draco в public/draco
npm run dev        # http://localhost:3000
```

Для экрана в музее лучше собранная версия:

```bash
npm run build
npm run start
```

## Графика

Переключатель «Графика: Низкая / Средняя» в верхней панели. Выбор запоминается в браузере, его можно задать ссылкой `?q=low` или `?q=medium`. При переключении сцена перезагружается и продолжает с того же места.

| | Низкая | Средняя |
|---|---|---|
| Файл | `public/models/botai.glb` (7 МБ) | `public/models/botai_mid.glb` (20 МБ) |
| Треугольников | ≈190 тыс. | ≈480 тыс. |
| Ассеты Megascans | Low, текстуры 1K | Mid, текстуры 2K |
| Трава | 9 тыс. кустов | 30 тыс. |
| Тени | 1024 | 4096 |
| Сглаживание, чёткость | выкл., 1× | вкл., до 2× |

`botai_mid.glb` экспортируется из `museium_web_mid.blend`.

## Управление

| Клавиша | Что делает |
|---|---|
| Пробел | пауза и продолжить |
| ← / → | предыдущий и следующий кадр |
| C | камера фильма или камера оператора |
| I | панель «О предмете» |
| H | показать или скрыть подсказку по управлению в левом нижнем углу |
| F | во весь экран |

В режиме оператора: левая кнопка мыши поворачивает камеру на месте (как штативная головка), правая облетает вокруг точки перед объективом, средняя сдвигает вбок и вверх, колесо везёт камеру вперёд и назад по направлению взгляда. W и S ведут камеру туда, куда смотрит объектив (в том числе вверх и вниз), A и D вбок, Q и E опускают и поднимают, Shift в четыре раза быстрее. Ползунок «Объектив» меняет фокусное расстояние (14–135 мм). Фильм продолжает идти, пока вы смотрите сами; пауза останавливает время.

Ссылка `?shot=5` открывает фильм с пятого кадра. После конца фильм ждёт 6 секунд и начинается снова (режим киоска).

## Как устроено

- `lib/shots.ts` — девять кадров, их кадры в Blender и затемнения.
- `lib/engine.ts` — сцена three.js: загрузка GLB, общая шкала времени для всех анимаций, переключение камер, смена эпох по `vis_start` / `vis_end` из Blender, небо, солнце, туман, трава, огонь, камера оператора.
- `components/Player.tsx` — интерфейс: верхняя панель, сцена, лента кадров, панель «О предмете», состояния загрузки и ошибки.
- `app/globals.css` — стиль по теме Darkroom из Hallmark (тёмный фон, узкие заглавные, один янтарный акцент).

Чтобы обновить сцену, экспортируйте GLB из `museium_web.blend` и замените `public/models/botai.glb`.

Шрифты Sofia Sans и Sofia Sans Extra Condensed лежат в пакетах `@fontsource`, интернет на экране не нужен.
